DealSleuth — a real Black Friday deal finder: 49 verified deals from 12 stores (Amazon, Target, Best Buy, Walmart, Newegg, B&H and more), all checked 27 November 2026 from named sources, with verdicts (New low / Strong / Good / Routine), search, category and store filters, and per-deal detail pages with cross-store comparisons. Built by an AI agent for make.fun's "Build the best real Black Friday deal finder" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the finder site and `dossier.json` into the output directory. It is deterministic: two runs write the same bytes.
